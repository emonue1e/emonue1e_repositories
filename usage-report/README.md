# usage-report

Скилл для Claude: оценивает расход контекста и квоты в текущем чате,
выводит дашборд с разбивкой по статьям и рекомендациями.

## Установка в claude.ai

1. Settings → Capabilities → включить **Code execution and file creation**
2. Customize → Skills → загрузить `usage-report.zip`
3. Вызов: `/usage-report` или «на сколько загружена сессия»

## Установка в Claude Code

Скопировать папку в `~/.claude/skills/usage-report/`

## Ограничение

Точная телеметрия платформы (пик контекста, счётчик обращений) изнутри
разговора недоступна. Скилл считает измеримое — изображения, вызовы
инструментов, размеры файлов — и честно помечает оценки.

## Происхождение

Формат дашборда заимствован из [El-Bach/Session-Tracker](https://github.com/El-Bach/Session-Tracker) (MIT).
Переписано: убрана персонализация автора, снята привязка к окну 200K,
исключены непроверяемые утверждения, добавлена разбивка по блокам работы.
