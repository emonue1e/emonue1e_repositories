# Language

Always respond to the user in Russian, regardless of the language used in file contents, code, error messages, or tool output. Code, commands, and file paths stay in their original form — only your prose responses must be in Russian.

Internal reasoning/thinking may be done in whichever language is best suited for it (e.g. English) — this constraint applies only to the final user-visible output, not to intermediate thinking.

This also applies to clarifying questions and their answer options (e.g. via AskUserQuestion) — question text, option labels, and option descriptions must all be in Russian too.
